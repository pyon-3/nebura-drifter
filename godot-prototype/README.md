# NEBURA DRIFTER Godot Prototype

Open this folder from Godot Project Manager and run `main.tscn`.

Controls:

- `W` / Up: accelerate
- `S` / Down: brake
- `A D` / Left Right: steer and drift

This prototype is intentionally isolated from the Three.js game. It is the minimum experiment for comparing Godot vehicle feel, camera behavior, and taillight afterimage rendering.
